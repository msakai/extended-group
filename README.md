# extended-group

When a field F does not contain elements satisfying both x + y = 1 and x y = 1, the set F ∪ {∞} forms a group under the operation defined as follows:

- ∞ ⊛ y = y
- x ⊛ ∞ = x
- x ⊛ y = (x y - 1) / (x + y - 1) if x + y ≠ 1
- x ⊛ y = ∞                        otherwise
