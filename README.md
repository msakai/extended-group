# extended-group

体 F が x + y = 1 かつ x y = 1 を満たすような元を持たない時、F ∪ {∞} は

- ∞ ⊛ y = y
- x ⊛ ∞ = x
- x ⊛ y = (x y - 1) / (x + y - 1)  if x + y ≠ 1
- x ⊛ y = ∞                        otherwise

で定義される演算によって群となることの証明。

元々は https://gist.github.com/msakai/42a4ff7ea7be32781ad646502f42765f の gist に書いていたもの。
